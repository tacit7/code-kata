def rob(nums): n = len(nums) if n == 1: return nums[0] def rob_range(start, end): prev_two = 0 prev_one = 0 for i in range(start, end): cur = max(prev_one, prev_two + nums[i]) prev_two = prev_one prev_one = cur return prev_one # Pass 1: skip last house p1 = rob_range(0, n - 1) # Pass 2: skip first house p2 = rob_range(1, n) return max(p1, p2)
Algorithm
Two-pass DP on a circular array.

Pass 1: Rob houses 0 to n-2 (skip last)

Pass 2: Rob houses 1 to n-1 (skip first)

Answer = max(P1, P2)
