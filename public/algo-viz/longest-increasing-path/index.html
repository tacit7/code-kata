Longest Increasing Path in a Matrix — DFS with memoization. From each cell, recurse into the 4 neighbors whose value is strictly greater. The result for a cell is 1 + max(results of valid neighbors). Memoize so each cell is computed once: O(m·n) total. For the default matrix the longest path is 1→2→6→9 (length 4).
